## 4. SA-S5-3 — Màn kết thúc (Opus chốt)

- Route riêng `CompletionScreen` (không dialog/
  overlay). File:
  `lib/features/completion/completion_screen.dart`.
- Constructor: `CompletionScreen({required String
  puzzleName, required Duration elapsed, int?
  bestSeconds})`.
- Hiển thị: tên puzzle + `"Time: <m>:<ss>"` +
  `"Best: <m>:<ss>"` nếu `bestSeconds != null`.
  Định dạng: `<m>` là tổng số phút, `<ss>` là giây
  dư hai chữ số (vd 125 giây → `Time: 2:05`).
- Nút "Play again": pop CompletionScreen, push lại
  `JigsawPlayScreen` cùng asset.
- Nút "Back to themes":
  `Navigator.of(context).popUntil((r) => r.isFirst)`.
- `Semantics(label: 'Completed', child: ...)` bọc
  toàn bộ scaffold.
- Timing: push SAU `await markSolved(...)` resolve
  (kể cả khi lỗi).

Điều chỉnh chữ (ghi rõ để Opus soát): constructor
của comment gốc chỉ liệt kê ba tham số dữ liệu,
nhưng WID-CP-05 (SA-S5-8) yêu cầu nút Play again
"gọi callback", và màn hình không tự giữ
asset/image/rng để tự dựng lại `JigsawPlayScreen`.
Contract bổ sung tham số tùy chọn
`VoidCallback? onPlayAgain`: nút Play again gọi
callback này khi được cấp; app shell cấp callback
thực hiện đúng hành vi đã chốt (pop màn kết thúc +
push `JigsawPlayScreen` cùng asset bằng
`pushReplacement`). Khi không có callback, nút
pop màn kết thúc (fallback cho test/widget độc
lập).

## 5. SA-S5-4 — Nguồn thời gian + chữ ký onCompleted (Opus chốt)

Thay đổi chữ ký là **chấp nhận được** trong S1-05
— controlled upgrade có hợp đồng rõ ràng;
WID-JP-10 được cập nhật trong chồng S1-05 (mục
này là căn cứ).

- **Chữ ký mới**: `final void Function(Duration
  elapsed)? onCompleted;`
- `JigsawPlayScreen` thêm `late final Stopwatch
  _stopwatch;` (khởi tạo trong `initState`).
- Bắt đầu: khi `_uiImage` được set lần đầu (trong
  `ImageStreamListener`, trước `setState`).
- Dừng: tại `justCompleted`, trước khi gọi
  callback.
- Gọi: `widget.onCompleted?.call(_stopwatch.elapsed);`
- WID-JP-10 update: `onCompleted: (elapsed) { ... }`,
  kiểm tra `elapsed >= Duration.zero` (và vẫn: gọi
  đúng 1 lần, kéo thêm bị khóa).

## 6. SA-S5-5 — Vòng đời DAO + ghi DB trong app shell (Opus chốt)

- `MyApp` giữ MỘT `ProgressDao` dùng chung:
  `AssetThemeProgressProvider` và `_openPuzzle`
  dùng cùng instance. Comment gốc phác:
  `final _dao = ProgressDao(AppDatabase.production());`
  hoặc constructor injection `MyApp({ProgressDao?
  dao})` cho test — contract thực hiện cả hai:
  `MyApp` thành `StatefulWidget`, State giữ
  `late final ProgressDao _dao = widget.dao ??
  ProgressDao(AppDatabase.production());` (một
  instance duy nhất cho cả vòng đời app; các
  override test hiện có `themeProvider`/
  `assetLoader` giữ nguyên).
- `onCompleted` trong `_openPuzzle` (nguyên văn
  comment gốc, chỉ đổi tên trường — xem điều chỉnh
  chữ bên dưới):

```dart
onCompleted: (elapsed) async {
  try {
    await dao.markSolved(
      asset.id, ProgressModes.jigsaw,
      solvedAt: DateTime.now(),
      timeSeconds: elapsed.inSeconds,
    );
  } catch (_) { /* log debug, không crash */ }
  if (!context.mounted) return;
  Navigator.of(context).pushReplacement(MaterialPageRoute(
    builder: (_) => CompletionScreen(
      puzzleName: asset.title.isNotEmpty ? asset.title : asset.theme,
      elapsed: elapsed,
      bestSeconds: elapsed.inSeconds, // S1-05: bản vừa ghi = best; query DB thực để lại S1-06+
    ),
  ));
},
```

- Lỗi `markSolved` chỉ log debug
  (`debugPrint`), không crash, vẫn hiện
  CompletionScreen.
- Play again (SA-S5-3): callback điều hướng do
  shell cấp — `pushReplacement` sang
  `JigsawPlayScreen` mới cùng asset, cùng image,
  cùng tolerance, `rng` theo SA-S5-2, và cùng
  handler hoàn thành này.

Điều chỉnh chữ (ghi rõ để Opus soát): (1) phác
thảo của comment gốc viết `asset.name` —
`PuzzleAsset` không có trường `name`; trường tên
puzzle của SA-4 (S1-01) là `title`, nên dùng
`asset.title.isNotEmpty ? asset.title :
asset.theme`. (2) Khóa asset của ảnh chơi là
`'content/' + asset.playPath` — `playPath` tương
đối so với `content/` (S1-01 §4); bản S1-04 chưa
có content thật nên tiền tố này chưa từng lộ diện,
thiếu nó ảnh thật không bao giờ nạp được. App
shell dùng `ResizeImage(AssetImage('content/' +
asset.playPath), width: 1080)`.
